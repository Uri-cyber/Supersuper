# מחירון בענן — אתר ציבורי בלי שרת ובלי עלות חודשית

האתר שב־`site/` הוא אתר סטטי. אין מאחוריו שרת: הדפדפן של הלקוח קורא את קובץ
מסד הנתונים ישירות מ־Cloudflare R2, חתיכות קטנות בכל פעם, לפי מה שהשאילתה צריכה.

| | |
|---|---|
| האתר | Cloudflare Pages, נמשך אוטומטית מ־GitHub |
| הנתונים | Cloudflare R2, קובץ אחד בגודל 1.95GB |
| עלות | 0 ש"ח לחודש |

## למה זה חינם

R2 נותנת 10GB אחסון ו**תעבורה בלי הגבלה ובלי חיוב**. מה שכן נספר הוא מספר
הבקשות: 10 מיליון בחודש. ביקור טיפוסי באתר צורך כ־53 בקשות, כלומר כ־188,000
ביקורים בחודש נכנסים במכסה החינמית. מעבר לכך המחיר הוא 0.36 דולר למיליון בקשות.

## הקמה חד־פעמית

**1. חשבון ודלי.** נרשמים ב־cloudflare.com, נכנסים ל־R2 ויוצרים דלי בשם `mehiron`.

**2. גישה ציבורית.** בהגדרות הדלי, תחת Public access, מפעילים `r2.dev` או מחברים
דומיין. חשוב גם להוסיף מדיניות CORS שמתירה לאתר לקרוא טווחי בתים:

```json
[{ "AllowedOrigins": ["*"],
   "AllowedMethods": ["GET", "HEAD"],
   "AllowedHeaders": ["range"],
   "ExposeHeaders": ["content-length", "content-range", "accept-ranges"] }]
```

**3. מפתחות.** ב־R2 בוחרים Manage API Tokens ויוצרים מפתח עם הרשאת כתיבה.
מעתיקים את הפרטים לקובץ `cloud/r2_config.json` לפי `r2_config.example.json`.
הקובץ הזה לא נכנס לגיט ואסור לשתף אותו.

**4. כתובת המסד.** ב־`site/config.js` מחליפים את `dbUrl` בכתובת הציבורית
של הקובץ, למשל `https://pub-xxxx.r2.dev/mehiron.db`.

**5. האתר.** ב־Cloudflare Pages בוחרים Connect to Git, מצביעים על המאגר,
ומגדירים את תיקיית הפלט `site`. אין פקודת בנייה.

## עדכון יומי

```
il-prices update          מוריד מהרשתות ומעדכן את prices.db
cloud\deploy.bat          בונה את מסד הענן ומעלה אותו
```

`deploy.bat` בונה קובץ חדש ומעלה אותו בחלקים של 64 מגה. אם החיבור נופל,
מריצים שוב וההעלאה ממשיכה מהמקום שנעצרה.

## למה האתר מהיר למרות שהמסד הוא 1.95GB

| מסך | בקשות | הורדה | זמן |
|---|---|---|---|
| פתיחה | 13 | 428KB | 0.5 שנ' |
| מסך הבית | 0 | 0 | מיידי |
| חיפוש | 10–26 | 24–124KB | 0.2–0.7 שנ' |
| עמוד מוצר | 21 | 356KB | 0.6 שנ' |
| סל | 16 | 336KB | 0.5 שנ' |
| בורסה | 0 | 0 | מיידי |

שלוש החלטות עשו את ההבדל:

**מה שזהה לכולם מחושב מראש.** מסך הבית, רשימת הבורסה, רשימת הערים ורשימת
הסניפים נשמרים כ־JSON בתוך המסד בזמן הבנייה. הם עולים בפתיחה ואחר כך לא
נדרשת אף בקשה. קודם מסך הבית לבדו הוריד 4.8 מגה.

**רשימת הסניפים נטענת לזיכרון.** בלעדיה כל עמוד מוצר היה מבצע 1,727 גישות
אקראיות למסד רק כדי לצרף שם עיר לכל מחיר.

**אינדקס החיפוש מסודר לפי פופולריות.** השורות הוכנסו אליו לפי מספר סניפים
יורד, ולכן `LIMIT 6` בלי מיון מחזיר כבר את הנפוצים ביותר ועוצר. עם `ORDER BY`
המנוע נאלץ לקרוא את כל רשימת ההתאמות: חיפוש המילה "חלב" הוריד כך 44 מגה.
התוצאות זהות בשתי השיטות, ונבדק שהן זהות.

## מגבלות

- **קריאה בלבד.** אין הרשמה, אין שמירת נתונים בצד השרת. הסל נשמר בדפדפן.
- **המסד מתעדכן רק כשמריצים `deploy.bat`.** אין עדכון אוטומטי.
- **הספרייה `sql.js-httpvfs` אינה מתוחזקת באופן פעיל.** היא עובדת, והעתק
  שלה שמור ב־`site/vendor/` כדי שהאתר לא יישבר אם היא תיעלם מהאינטרנט.

## בדיקה מקומית לפני העלאה

```
python cloud\build_cloud_db.py --page-size 4096
copy cloud\mehiron-4096.db site\mehiron.db
python cloud\range_server.py --port 8778 --delay 20
```

`--delay 20` מוסיף השהיה מדומה של 20 מילישניות לכל בקשה, כדי שהמדידה תשקף
אינטרנט אמיתי ולא localhost. הכתובת: `http://127.0.0.1:8778/`.

מונים חיים: `http://127.0.0.1:8778/__stats`.
