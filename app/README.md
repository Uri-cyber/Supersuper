# מחירון — האפליקציה ללקוחות

אתר בעברית שמראה ללקוחות איפה כל מוצר הכי זול, לפי הנתונים שרשתות המזון מחויבות לפרסם.
האתר קורא את אותו `prices.db` שהכלי `il-prices` בונה, ולא מחזיק נתונים משלו.

## איך מפעילים

לחיצה כפולה על **`מחירון.bat`** בתיקייה הראשית. הדפדפן ייפתח לבד.
לעצירה: סוגרים את החלון השחור.

בפעם הראשונה הקובץ בונה אינדקס (כשלוש דקות). אחרי זה ההפעלה מיידית.

## איך נותנים ללקוחות גישה מהטלפון

לחיצה כפולה על **`מחירון-ברשת-הביתית.bat`**. יופיעו כתובות כמו `http://192.168.1.14:8000/`.
כל מי שמחובר לאותו ראוטר יכול להיכנס לכתובת הזו מהטלפון.

> האתר פתוח רק ברשת המקומית. כדי לפרסם אותו לאינטרנט צריך שרת ודומיין, וזה שלב נפרד.

## חמשת המסכים

| מסך | מה הוא עושה |
|---|---|
| **חיפוש** | חיפוש מוצר לפי שם או ברקוד, הפער הגדול של היום, והמוצרים עם הפערים הגדולים |
| **מוצר** | המחיר בכל סניף בארץ, מהזול ליקר, עם סינון לפי עיר ורשת, גרפים ומפה |
| **סרוק קבלה** | מדביקים את שורות הקבלה ורואים כמה אותו סל היה עולה בסניף הזול |
| **בורסת המחירים** | 120 המוצרים הנפוצים, מה עלה ומה ירד מאז העדכון הקודם |
| **הסל שלי** | כמה עולה הסל בכל רשת, מה הסניף הזול ביותר, ומה חוסך פיצול בין שתי חנויות |

## עדכון הנתונים

האתר מציג את מה שיש ב־`prices.db`. כדי לרענן, מריצים פעם ביום:

```bash
il-prices update
```

ואז מפעילים מחדש את `מחירון.bat` (הוא בונה את האינדקס מחדש לבד כשהנתונים משתנים).

## מה האתר לא ממציא

- **תאריך ליד כל מחיר.** אין השוואה בין מחיר של היום למחיר בן חודשיים.
- **ברירת מחדל: 7 ימים אחרונים.** מחירים ישנים יותר מושמטים, והאתר כותב כמה הושמטו.
- **"לא ידוע"** בכל מקום שהרשת לא פרסמה עיר או כתובת, עם הסבר מה חסר.
- **רשת בלי קובץ סניפים** (יילו, סיטי מרקט) מסומנת ככזו, והסניפים שלה מופיעים במספר בלבד.
- **אין תמונות מוצר** כי הרשתות לא מפרסמות אותן. במקום זה יש ריבוע צבעוני.
- **אין קטגוריות** מאותה סיבה. במקומן מוצג מספר הסניפים והרשתות שמוכרים את המוצר.
- **המפה מקורבת**: הנקודה היא מרכז היישוב, לא כתובת הסניף. עיר בלי קואורדינטות לא מוצגת.

## מסך הקבלה

הרשתות לא מפרסמות קבלות, ולכן **אין סריקה מצילום**. הלקוח מדביק טקסט:
קבלה דיגיטלית מהמייל, מאפליקציית הרשת, או פשוט רשימת ברקודים.

```
2 x חלב תנובה 3% 1 ליטר   14.40
קוטג' תנובה 5%   6.90
7290004131074   7.20
```

מחיר בסוף השורה הוא רשות. בלעדיו האתר עדיין ימצא את הסניף הזול, אבל לא יוכל
להראות כמה שולם יותר מדי. שורות שלא זוהו מוצגות בנפרד ולא נכנסות לחישוב.

## קבצים

| קובץ | תפקיד |
|---|---|
| `app/server.py` | השרת וה־API. ללא ספריות חיצוניות |
| `app/build_index.py` | בונה טבלאות עזר כדי שהאתר יגיב מיד |
| `site/` | האתר עצמו: `index.html`, `app.js`, `data.js`, `styles.css` |
| `cloud/` | בניית מסד לענן והעלאה ל-R2. ראו [cloud/README.md](../cloud/README.md) |
| `../prices.db` | הנתונים. נבנה על ידי `il-prices update` |

## אותו אתר, שתי דרכי הרצה

התיקייה `site/` היא הממשק היחיד. `site/data.js` יודע לקרוא נתונים משני מקורות:

- **מקומי**: `מחירון.bat` מפעיל את שרת הפייתון, שמגיש את `site/` ומייצר `config.js`
  שמורה לקרוא ל-`/api`. כל הנתונים זמינים, כולל היסטוריה.
- **בענן**: אותם קבצים בדיוק מועלים ל-Cloudflare Pages, ושם `config.js` מורה
  לקרוא את המסד ישירות מ-R2. ראו [cloud/README.md](../cloud/README.md).

כך אין שני עותקים של הממשק שצריך לתחזק.

## פתרון תקלות

**"Python was not found"** — התקינו מ־python.org וסמנו "Add Python to PATH".

**הדפדפן לא נפתח** — היכנסו ידנית ל־`http://localhost:8000/`.

**"הפורט תפוס"** — הריצו `מחירון.bat --port 8010`.

**האתר מציג נתונים ישנים** — הריצו `il-prices update` ואז הפעילו מחדש.
