# il-prices – השוואת מחירי סופרמרקט בישראל לפי סניף

הכלי מוריד את קובצי המחירים הרשמיים של כל רשתות המזון (חוק שקיפות המחירים),
שומר אותם במסד נתונים מקומי (`prices.db`) ומאפשר לבדוק איפה הכי זול לקנות.

## התקנה חד-פעמית
1. ודאו ש-Python 3.10 ומעלה מותקן (https://www.python.org/downloads/ – בהתקנה סמנו "Add Python to PATH").
2. פתחו את התיקייה `il-prices` בסייר הקבצים, לחצו על שורת הכתובת למעלה, כתבו `cmd` ולחצו Enter.
   נפתח חלון שחור – שם מקלידים את הפקודות. הספריות הנדרשות יותקנו לבד בהרצה הראשונה.

## 3 הפקודות שצריך

**1. עדכון המחירים (פעם ביום, לוקח זמן – אפשר להשאיר ברקע):**
```
il-prices update
```

**2. חיפוש מוצר וקבלת מחירים בכל הסניפים, מהזול ליקר (ו-history לנתוני עבר):**
```
il-prices search "חלב תנובה 3%"
il-prices price 7290004131074 --city "תל אביב"
```

**3. סל קניות – הסניף הזול ביותר לכל הסל והפיצול המשתלם ביותר:**
```
il-prices basket basket.txt --city "ירושלים"
```
עורכים את הקובץ `basket.txt` (ברקוד בכל שורה, אפשר כמות אחרי רווח).
בלי `--city` החיפוש הוא בכל הארץ. `--max-stores 2` מציג גם את הפיצול הטוב ביותר לשני סניפים בלבד.

## אפליקציה ללקוחות
לחיצה כפולה על `מחירון.bat` פותחת אתר בעברית עם חיפוש, השוואת סניפים, בדיקת קבלה, בורסת מחירים וסל קניות.
`מחירון-ברשת-הביתית.bat` פותח אותו גם לטלפונים באותה רשת. ההסבר המלא: [app/README.md](app/README.md).

## דיוק הנתונים
- ליד כל מחיר מופיע התאריך שבו הרשת פרסמה אותו. אם ההשוואה מערבבת תאריכים שונים תופיע אזהרה.
- כדי להשוות רק מחירים מיום מסוים: `il-prices price 7290004131074 --date 2026-09-03` או `il-prices basket basket.txt --date 2026-09-03`.
- הכלי לא מנחש שום דבר. עיר או כתובת שהרשת לא פרסמה מופיעות כ"לא ידוע", והסיבה כתובה בעמודת "הערות".
- רשת שלא מפרסמת קובץ סניפים בכלל (למשל יילו) מופיעה כ"סניף 12" עם ההערה "הרשת לא מפרסמת קובץ סניפים".
- `il-prices update --stores-only --force-stores` בונה מחדש את רשימת הסניפים מקובצי הרשתות.

## נתוני עבר
- כל הרצה של `il-prices update` שומרת בהיסטוריה את המחירים שהשתנו מאז ההרצה הקודמת (רק שינויים, כדי שהמסד לא יתנפח).
- `il-prices history 7290004131074 --city "חיפה"` מציג לכל תאריך את המחיר המינימלי, הממוצע והמקסימלי, ואת הסניפים שבהם המחיר השתנה.
- ההיסטוריה מתחילה להיצבר מהיום הראשון שבו הרצתם update; אין דרך לקבל מהרשתות מחירים מלפני חודשים. אתרי הרשתות שומרים בדרך כלל רק כמה ימים אחורה, ואפשר למשוך יום כזה עם `il-prices update --date 2026-09-01`.
- המסד כבר מכיל את כל העבר שהרשתות מפרסמות באתרים שלהן (לכל רשת עומק אחר: רמי לוי כ-50 יום, משנת יוסף 2 כ-250 יום, ורשתות רבות רק את היום). `il-prices stats` מציג את הטווח.
- `price` ו-`basket` מציגים כברירת מחדל רק מחירים מ-7 הימים האחרונים, ומודיעים כמה מחירים ישנים יותר הושמטו (סניפים שהרשת הפסיקה לפרסם). `--include-old` מציג גם אותם.
- כדי לצבור היסטוריה מלאה כדאי להריץ `il-prices update` כל יום (למשל דרך "מתזמן המשימות" של Windows).

## טיפים
- `il-prices stats` מציג כמה רשתות וסניפים יש במסד.
- `il-prices update --chains RAMI_LEVY,SHUFERSAL` מעדכן רק רשתות מסוימות (מהיר יותר).
- ההורדה חייבת לרוץ ממחשב בישראל – אתרי הרשתות חוסמים כתובות מחו"ל.
- חלק מהרשתות נופלות מדי פעם; הכלי ממשיך עם השאר ומדפיס מה נקלט.
- אם העברית מופיעה כג'יבריש בחלון השחור, הריצו קודם `chcp 65001`.
- אם מופיעה ההודעה "is not recognized", כתבו `.\il-prices` במקום `il-prices` (למשל `.\il-prices update`).
- העדכון הראשון מוריד עשרות ג'יגה של קבצים ועלול לקחת שעה ויותר; הקבצים נמחקים אחרי הקליטה, ורק `prices.db` נשאר.
